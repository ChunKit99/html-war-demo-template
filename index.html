WildFly demo

Static HTML to WAR

This folder shows how a plain HTML, CSS, and JavaScript site can be packaged into a WAR and deployed to WildFly. The sample stays framework-free and does not depend on any business-specific data.

Open the sample page

What this demo shows

  • A static page served from the WAR root
  • A small interactive page with vanilla JavaScript
  • A batch script that packages the files with the JDK jar tool
  • No framework, no backend, and no domain-specific content

Files included in the WAR

index.html
sample-form.html
style.css
create_war_file.bat

Deploy the generated WAR in WildFly and open the root page in a browser.

Packaging command

jar cvf static-html-war-demo.war index.html sample-form.html style.css

The batch file wraps this command, removes any previous WAR, and builds a fresh package from the current folder.

Run the sample

Open sample-form.html for a runnable page that uses local JavaScript only. It previews the entered values so the page can be tested without a backend.
